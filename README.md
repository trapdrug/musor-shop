# MUSOR SHOP - NFT-калькулятор

Фиолетовый NFT-калькулятор с floor-ценами Portals/Tonnel.

- Сайт: https://trapdrug.github.io/musor-shop/
- Прокси floor-цен: см. proxy/README.md (деплой на Vercel, ~3 мин).

## Что умеет калькулятор

Две вкладки:

1. **Расчёт покупки и продажи**
   - строка 1 — курс доллара к рублю (вводится вручную, запоминается в браузере);
   - строка 2 — спотовая цена GRAM/USDT с Bybit (авто-обновление раз в минуту);
   - строка 3 — сколько монет потратил (к этому количеству автоматически прибавляется **0.35 монеты**);
   - строка 4 — значение X (цена продажи): из X вычитается 10%, затем ещё 6%;
   - строка 5 — название подарка (**необязательно**);
   - профит считается как `продажа − покупка − 60 ₽` (фиксированный вычет 60 ₽).
2. **Цена продажи по профиту**
   - вводишь потраченные монеты и желаемый профит в рублях;
   - калькулятор выдаёт, за сколько ₽ нужно продать подарок (после комиссий 10% + 6%),
     значение X для строки 4 и цену в монетах.

Общие правила:

- расчёт запускается кнопкой **«Рассчитать»** или клавишей **Enter** в любом поле (работает на ПК);
- список подарков и лидерборд с сохранением удалены — ничего не сохраняется, кроме курса доллара.
